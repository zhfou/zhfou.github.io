# 在 Hyper‑V 上运行 OpenWrt

> 
本文简单介绍如何在 Hyper‑V 上安装和配置 OpenWrt，以及将 OpenWrt 作为旁路由接管本机流量的基础过程。
这些步骤在 VMware WorkStation / VMware EXSi / Proxmox VE / 其他 KVM 虚拟化平台大体相通。如果你希望把 OpenWrt 虚拟机用作软路由，本文同样具备参考价值。

## 准备工作

1. 确认电脑支持 Hyper‑V 功能，后文会介绍确认方法。
2. 部分下载操作可能需要访问国际网络。

## 第一步：开启 Hyper‑V 功能

Hyper‑V 是微软面向 Windows 专业版/企业版、Windows Server 的虚拟化平台，可与新版 VMware Workstation 共存。

需要确认两件事：

1. 本机是否可以启用 Hyper‑V
2. 如何启用 Hyper‑V

### 确认能否启用 Hyper‑V

本质是确认 Windows 系统版本。查看版本方式：

1. Windows Vista /7 /8.x：控制面板 → 系统与安全 → 系统
Windows10：设置 → 系统 → 关于
Windows11：设置 → 系统 → 系统信息
2. Win+R，执行 `winver`

> 
> ✅ 可启用：专业版、专业工作站版、企业版、教育版、Server 版本
> ❌ 家庭版/家庭中文版：本文流程不适用，可自行搜索家庭版开启 Hyper‑V 的教程。

### 启用 Hyper‑V

1. `Win+R` 输入 `control` 打开控制面板 → 程序 → 启用或关闭 Windows 功能
2. 勾选以下三项：
   - Hyper‑V
   - Windows 虚拟机监控程序平台
   - 虚拟机平台> 
   > 只需保证以上三项勾选，其余选项不必完全一致。
3. 点击确定等待安装，**完成后务必重启电脑**，后续步骤必须重启后继续。

## 第二步：下载 OpenWrt 硬盘镜像并转换格式

### 下载 OpenWrt 镜像

前往 OpenWrt 官网下载稳定版镜像，选择架构：`x86‑64`。
存在两类镜像：

- `generic‑ext4‑x.img`：全部修改持久化保存
- `generic‑squashfs‑x.img`：修改不持久化，重启恢复默认，便于配置出错重置，**本文推荐使用**

下载时二选一：

- `generic‑x‑combined.img.gz`：传统 BIOS 引导
- `generic‑x‑combined‑efi.img.gz`：UEFI 引导

> 
> ⚠️ 记住镜像引导方式，直接决定 Hyper‑V 虚拟机的世代。

> 
> 作者使用 Github @DHDAXCW 编译的 `OpenWrt_x86_x64`，该镜像同时支持 BIOS+UEFI，预置常用插件，可以在其 Release 页面下载。
> 使用第三方镜像务必确认其引导方式。

### 转换镜像格式至 .vhdx

下载解压后得到 `.img`，Hyper‑V 不能直接识别，需要转为 `.vhdx`，两种方案。

#### 方案一：使用 qemu‑img

1. 下载 Windows 版 QEMU，安装时仅勾选 `Tools` 和 `DLL Library`（只需要 qemu‑img 工具）。

> 
> 注意：安装程序不一定自动加入系统环境变量，命令行需要 cd 到安装目录，或者手动添加环境变量。
2. 打开 PowerShell / Windows 终端，cd 到镜像所在目录。

```
qemu-img convert -p -f raw -O vhdx your_image.img your_image.vhdx
```

执行完成即得到 Hyper‑V 可用的 vhdx 文件。

#### 方案二：StarWind V2V Converter（图形界面，适合不熟悉命令行）

1. 下载安装 StarWind V2V Converter。
2. 选择源：`Local File`，选中你的 `.img`。
3. 目标：`Local File`，格式选择 `VHDX Growable Image` / `VHDX Pre‑allocated`，执行转换。

转换完成后把 `.vhdx` 文件放到便于访问的目录。

## 第三步：创建并配置 Hyper‑V 虚拟机

### 配置虚拟网络交换机

#### 虚拟交换机三种类型

1. **内部虚拟交换机**：虚拟机 ↔ 物理主机通信；默认**不能访问外网**，适合管理虚拟机。
2. **外部虚拟交换机**：绑定物理网卡，让虚拟机直接访问外网，等同于给虚拟机一张物理网卡。
3. **专用虚拟交换机**：仅虚拟机之间互通，不能和物理主机、外网通信。

> 
> 本文目标：OpenWrt 做 Windows 旁路由：需要 **内部交换机（管理） + 外部交换机（WAN 外网）**。
> 如果是物理软路由场景，则创建两个外部交换机。

#### 创建虚拟网络交换机

1. 打开「Hyper‑V 管理器」，连接本地计算机。
2. 打开「虚拟交换机管理器」。
3. 新建两个交换机：
   - **内部虚拟交换机**：全部保持默认。
   - **外部虚拟交换机**：绑定你本机正在上网的物理网卡（无线网卡/有线网卡，看你实际上网方式）。
4. 点击应用，等待创建完成。

### 创建 Hyper‑V 虚拟机

1. Hyper‑V 管理器 → 新建 → 虚拟机，打开向导。
2. 填写虚拟机名称，选择存储位置。
3. **指定代数**：
   - BIOS 引导镜像 → 第一代；
   - UEFI 引导镜像 → 第二代（推荐）。
4. 内存：至少 `1024MB`，示例分配 `1536MB`，**关闭动态内存**。
5. 配置网络：先选择刚才创建的**内部虚拟交换机**。
6. 连接虚拟硬盘：选择「使用现有虚拟硬盘」，选中转换好的 `.vhdx`。
7. 确认摘要，点击完成创建虚拟机。

#### 修改虚拟机额外设置

1. 右键虚拟机 → 设置 → 添加硬件 → 网络适配器，添加刚才的**外部虚拟交换机**。
2. 选中新增的外部网卡 → 展开高级功能 → **勾选启用 MAC 地址欺骗**，应用。
3. 切换到「安全」页面，**取消勾选启用安全启动**，否则 OpenWrt 无法引导。

至此虚拟机开机前配置全部完成。

## 第四步：配置 OpenWrt 虚拟机

1. Windows 打开终端执行

```
ipconfig
```

记录物理网卡/外部虚拟交换机的 IP、网段、默认网关。示例网段：`192.168.31.*`。

### 虚拟机内终端配置

1. Hyper‑V 管理器连接虚拟机，点击启动。
2. 等待约 30 秒，按下回车进入 OpenWrt tty 终端。
3. 编辑网络配置文件：

```
vim /etc/config/network
```

按下 `i` 进入编辑模式，找到 `option ipaddr '192.168.11.1'`，把 LAN IP 修改为空闲内网 IP，示例改为：

```
option ipaddr '192.168.35.1'
```

按 `Esc`，输入 `:wq` 保存退出。

重载网络配置：

```
service network reload
```

> 
> 此时可以浏览器访问修改后的 LAN IP，进入 OpenWrt Web 后台。

### Web 浏览器后台配置

- 默认账号：`root`；默认密码：`password`，登录后建议修改密码。
- 进入「网络 → 接口」编辑 WAN：

1. 协议切换为「静态地址」
2. IPv4 地址：填入同网段静态IP，示例：`192.168.31.70`
3. IPv4 网关：填写 Windows 主机获取到的网关（如 `192.168.31.229`）
4. IPv4 广播：`192.168.31.255`
5. DNS：主 `8.8.8.8`，副 `8.8.4.4`
6. 子网掩码：`255.255.255.0`
7. DHCP 设置：勾选「忽略此接口」

保存&应用。正常情况下虚拟机即可上网，流量经过 OpenWrt。

## 配置 OpenWrt 虚拟机的另一种方式（ICS 网络共享，适合校园网/Wi‑Fi动态IP）

适用场景：WiFi IP 经常变化、校园网网页认证等环境。

> 
> 前置：把 OpenWrt 虚拟机关机。

### 什么是 Windows ICS 服务

Windows Internet Connection Sharing（ICS）：Windows 自带网络共享，把一个网卡网络共享给另一个网卡。

> 
> ICS 默认固定网段：`192.168.137.*`。

> 
> ⚠️ 注意事项：
> 方案A：已有内部交换机占用该网段，则新建一个内部交换机给 OpenWrt，开机后调整 eth0/eth1 对应 wan/lan。
> 方案B：启动 OpenWrt 修改 LAN IP，避开 `192.168.137.*`。

### 启用 Windows ICS 服务

1. `Win+R` 输入 `services.msc`，打开服务管理器。
2. 找到 `Internet Connection Sharing (ICS)`。
3. 属性：启动类型设置为**自动**，点击启动该服务。

### 创建并使用新的虚拟网络交换机

1. 虚拟交换机管理器，删除旧的外部虚拟交换机。
2. 新建一块**内部虚拟交换机**（示例命名 `vlan_wan_ics`）。
3. 虚拟机设置，把原来的外部网卡替换为此新建内部交换机。

### 设置 Windows 网络适配器共享

1. 控制面板 → 网络和 Internet → 网络和共享中心 → 更改适配器设置。
2. 右键你本机正在上网的物理网卡 → 属性 →「共享」选项卡。
3. ✅ 勾选：`允许其他网络用户通过此计算机的 Internet 连接来连接`。
4. 家庭网络连接下拉框，选中刚才新建的内部交换机（`vlan_wan_ics`）。
5. **不要勾选：允许其他网络用户控制或禁用共享的 Internet 连接**。确定应用。

### OpenWrt Web 修改 WAN 接口

开机，访问 OpenWrt LAN IP，进入后台，编辑 WAN：

1. 协议切换为静态地址
2. IPv4 地址：`192.168.137.2`（`192.168.137.*`，不能是`.1`）
3. IPv4 网关：`192.168.137.1`（ICS固定地址）
4. 广播地址：`192.168.137.255`
5. DNS：`8.8.8.8`、`8.8.4.4`
6. 子网掩码：`255.255.255.0`
7. DHCP：勾选忽略此接口

保存&应用。网络正常即可使用。

### Windows ICS 的已知问题

> 
> ICS 特性：空闲约4分钟无流量会自动关闭；系统重启后 ICS 共享会失效。
> 临时方案：每次开机重新设置网络共享。
> 长久方案：Win10 1709及以后版本，修改注册表实现 ICS 持久化。

## 结语

至此完成从开启 Hyper‑V、镜像转换、虚拟机创建、OpenWrt 网络配置全部流程。
